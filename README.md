# EduVoyage - Modern Learning Management System

![EduVoyage Banner](https://via.placeholder.com/1200x400/4a90e2/ffffff?text=EduVoyage+LMS+Portal)

EduVoyage is a comprehensive Learning Management System (LMS) designed to provide an intuitive and engaging online learning experience. This platform connects students and educators in a seamless digital environment.

## ✨ Features

- **User Authentication**
  - Secure login and registration system
  - User profile management
  - Teacher and student role-based access

- **Course Management**
  - Browse and enroll in various courses
  - Interactive video lessons
  - Course progress tracking

- **Teacher Portal**
  - Create and manage courses
  - Upload educational content
  - Track student progress

- **Interactive Learning**
  - Video lectures
  - Course materials and resources
  - Progress tracking and certificates

## 🚀 Getting Started

### Prerequisites
- Web browser (Chrome, Firefox, Safari, or Edge)
- Internet connection

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/abhi22maurya/EduVoyage.git
   ```
2. Navigate to the project directory:
   ```bash
   cd EduVoyage/SIH 2Project
   ```
3. Open `home.html` in your web browser
